Настройка публикации на GitHub Pages

Нужно один раз, с компьютера. Мастер соберёт два файла, которые вы положите в репозиторий рядом с index.html. После этого редактор на сайте сможет сохранять правки сам — пароль останется единственным, что нужно помнить.

  1. Создайте публичный репозиторий, например am-reglament, и загрузите в него всё содержимое папки site/ (без server.py, server.config.json и history/).
  2. Включите Pages: Settings → Pages → Source: Deploy from a branch → main / (root).
  3. Создайте токен: Settings → Developer settings → Personal access tokens → Fine-grained, доступ только к этому репозиторию, право Contents: Read and write, срок — по желанию.
  4. Заполните поля ниже и нажмите «Собрать файлы». Токен никуда не отправляется: он шифруется прямо в браузере вашим паролем.
  5. Скачайте site-config.json и admin.lock.json, добавьте их в репозиторий, подождите минуту — откройте /admin.html на сайте Pages и войдите тем же паролем.
